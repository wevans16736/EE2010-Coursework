# Electrical Engineering 2010 (Circuits) Coursework (Iowa State University)
## Wyatt Evans, Fall 2026

This repo contains the lab files for Wyatt Evans at Iowa State University for CprE 2810 of fall 2026.
### Topics Covered:
#### Ohm's Law
$V=IR$, $I=\frac{V}{R}$, $R=\frac{V}{I}$
#### Basic Circuits
- Voltage Dividers and Resistor Networks
- Thevenin and Norton Equivalent Circuits
#### Circuit Analysis Techniques
- Kirchoff's voltage and current laws
- Node Voltage and Mesh Current
- Source Transformation
- Superposition
- Thevenin Equivalent
#### Dependent Sources
Utilizing circuit analysis techniques such as source deactivation (in order to find contribution per individual source towards total voltage or current) to determine voltage or current at a dependent source
#### Operational Amplifiers
Solving for voltages and currents at the output of different operational amplifiers, analyzing cascading operational amplifiers at nodes where nodal analysis is required
#### Inductors and Capacitors
Determine behavior of circuits involving inductors and/or capacitors in steady states and as a function of time
